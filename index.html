Drei funktionsfähige Prototypen — vom Vereinsauftritt bis zur Live-Anwendung. Kein Mockup, echter Code, jeder klickbar. So sieht eine Lösung von GoalLink in echt aus, bevor sie auf euren Verein zugeschnitten wird.

Backend: C# / ASP.NET Core
Frontend: React
Fokus: Fußball & Sport
